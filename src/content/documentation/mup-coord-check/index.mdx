# Setup

We train the same 2-layer dense GQA model (gpt_trainstation in torchtitan) for 20 AdamW steps at widths 128 to 4096, and record the RMS of every activation on a fixed 512-token probe sequence. Under SP (standard parameterization) the activation scale grows with width as soon as training starts. Under muP it stays flat.

# Growth exponents

For each activation we fit the slope `p` of log RMS against log width, so that RMS ∝ width<sup>p</sup>. Zero means the activation scale doesn't depend on width.
