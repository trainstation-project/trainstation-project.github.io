# Setup

We compare the tokenizers of DeepSeek-V4, GLM-5, Kimi K3, Marin, Qwen3.8 and Beam 1.0. Every plot uses the same encoding:

- **Solid** marks are each tokenizer as shipped. Qwen3.8 and Beam 1.0 already split digits singly.
- **Hatched** marks are a single-digit (1-digit) variant of DeepSeek-V4, GLM-5, Kimi K3 and Marin.
- **Cross-hatched, outlined** marks are Marin with single digits and newline splitting.

# Code syntax alignment

Alignment is the share of syntax spans in parsed code whose boundaries fall on token boundaries; higher is better.

<Figure id="fig-ast-alignment" wide>
  <Image src={astAlignment} width={2080} alt="Three bar charts of alignment rate across 12 languages: fully aligned, start-aligned and end-aligned. Fully aligned ranges from 0.502 to 0.584, with Marin (1-digit, newline split) and Qwen3.8 highest at 0.584; end-aligned is 0.805 for both of those and 0.674 to 0.691 for the rest." />
  <Fragment slot="caption"><strong>Code AST boundary alignment.</strong> Share of syntax spans whose start and end, start only, or end only fall on token boundaries, pooled over 12 languages.</Fragment>
